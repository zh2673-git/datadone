# 多源数据分析系统 - 纪委初核分析助手

面向纪委初核场景的多源数据分析系统，自动处理银行账单、微信账单、支付宝账单和话单数据，生成结构化的 Excel 详表 + Word 解读式分析报告。

## 功能特性

- **多源数据加载**：支持银行、微信、支付宝、话单四种数据源，自动识别文件类型
- **智能文件夹扫描**：递归扫描 `data/` 目录，自动识别人物文件夹及其中数据文件
- **批量分析**：多人独立分析，每人生成独立报告
- **合并分析**：多人数据合并统一分析，发现跨人员资金往来关系
- **全维度分析引擎**：
  - 频率分析（交易对手统计）
  - 存取现识别（大额/同日/连续取现标记）
  - 特殊金额检测（爱情数字/吉利数字/规避阈值）
  - 特殊日期交易（节假日大额）
  - 综合交叉分析（通话+资金双平台交叉）
  - 行为基线与异常检测（σ偏离度）
  - 行为模式识别（周期性收入/资金中转/规避检测）
  - 时序链发现（通话→资金关联证据链）
  - 风险研判（四维度评分+调查建议）

## 快速开始

### 安装依赖

```bash
pip install -e .
```

需要 Python ≥ 3.10。

### 数据准备

将数据文件放入 `data/` 目录，支持两种组织方式：

**方式一：多人物文件夹（推荐）**

```
data/
  0707城管5人分类汇总/
    张三一家/
      张三账单数据预览.xlsx    ← 银行（文件名含"账单/银行/流水"）
      张三微信账单浏览.xlsx    ← 微信（文件名含"微信"）
      话单数据预览.xlsx        ← 话单（文件名含"话单/通话"）
    李四一家/
      ...
```

**方式二：单文件模式**

```
data/
  银行账单.xlsx
  微信账单.xlsx
  话单数据.xlsx
```

### 运行

```bash
python main.py
```

交互式菜单会自动识别数据组织方式：

```
============================================================
  多源数据分析系统 - 纪委初核分析助手
============================================================

[已识别 5 个人物文件夹]
  1. 张三一家 (bank/wechat/call)
  2. 李四一家 (bank/wechat/call)
  ...

请选择操作：
  1. 选择人员并批量分析（推荐）
  2. 全部人员批量分析
  3. 合并分析（所有人放一起分析，生成统一报告）
  4. 加载数据（手动指定文件）
  5. 执行分析
  6. 导出报告
  7. 一键运行（单人模式）
  8. 退出
```

## 报告输出

分析完成后在 `output/` 目录生成两种格式报告：

```
output/
  张三一家/
    分析报告.xlsx
    分析报告.docx
  合并分析/
    分析报告.xlsx
    分析报告.docx
```

### Excel 报告（10个工作表）

| 工作表 | 内容 |
|--------|------|
| **分析汇总表** | 每人每平台收支汇总（存现/取现/转账分类） |
| **存取现明细表** | 逐笔存取现记录，含大额标记(★)、同日存取/连续取现备注 |
| **重点收支明细表** | 重点收支+特殊金额+特殊日期+规避阈值交易，按类型着色 |
| **账单类频率表** | 交易对手收支统计，含收入/支出占比 |
| **话单类频率表** | 通话频率统计，含对方单位、特殊时间通话 |
| **综合分析表** | 跨平台交叉分析，标注交叉类型（双平台交叉/仅账单/仅话单） |
| **大额资金跟踪表** | 大额资金流向逐笔跟踪，含通话关联 |
| **异常明细表** | 异常行为逐条记录，含偏离度、严重程度、基线对比 |
| **行为发现表** | 行为模式+时序链合并呈现，含匹配度、关键证据 |
| **风险研判表** | 行为基线指标+四维度风险评分+调查建议 |

**Excel 条件格式示例：**

| 列 | 着色规则 |
|----|----------|
| 交易金额 | ≥5万整行红色高亮 |
| 大额标记 | ★行橙色高亮 |
| 存取现标识 | 存现/取现黄色高亮 |
| 综合风险等级 | 高风险红/中风险黄/低风险绿 |
| 严重程度 | 高红色/中黄色 |
| 交叉类型 | 双平台交叉绿色高亮 |
| 重点类型 | 规避阈值红/特殊金额绿/特殊日期蓝/工作收入浅绿 |

### Word 报告（解读式初核分析报告）

Word 报告遵循**"解读而非报数，聚合而非罗列，指向而非复述"**原则，聚焦初核关注点，详表引导查阅 Excel。

**报告结构：**

```

  （分析时间：20XX年XX月XX日）

  · 数据可靠性评估（充足/一般/不足）

  │  合计  │ xxx,xxx  │ xxx,xxx  │ 净流入xxx,xxx│
  └────────┴──────────┴──────────┴──────────────┘
  数据跨度X个月，月均收入X元、支出X元。总体净流入X元……

  存取现情况
  存现X元，取现X元，存取现占收支比X%（偏高/正常）。
  其中单笔万元以上存取现X次、合计X元……
  存取现前后有通话记录X次，其中X次可关联到通话对方……

  关键收支特征
  工作收入X元（X笔，疑似XX）；房产收入X元；……
  ⚠ 收入来源差异：可识别工作收入月均约X元，远低于实际月均收入X元……
  特殊金额交易：爱情数字X笔共X元（如520/1314等）；其他特殊金额X笔共X元……
  特殊日期交易：节假日期间大额交易X笔共X元（春节X笔、中秋X笔……）

三、重点发现
  核心交易对手
  ┌──────────┬──────────┬──────────┬──────────┬────────────────┐

  检测到异常行为X项（大额偏离X项、频次异常X项……），其中高严重X项；
  识别行为模式X次（周期性收入X次、资金中转X次……，最高匹配度XX%）；
  大额资金跟踪X条（直接X条、一层间接X条）。
    ⚠ [大额偏离] X月收入X元偏离基线X个σ（对方：XXX）
    ⚠ [频次异常] 与XXX交易频次……
```

## 配置说明

- `config/keywords.json`：关键词库，定义重点收支匹配关键词（工资/租金/房产等）和行为模式关键词
- `config/thresholds.json`：阈值配置，包括大额交易阈值、偏离度阈值、风险评分权重等
- `config/config.json`：基础配置，数据源字段映射等
