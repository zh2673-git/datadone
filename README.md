# DataDone-RE 多源数据分析系统

> **v1.1.0** | 基于"数据规矩-存储-流转-接口"四层架构的全新重构版本，新增可选 AI 协同层

面向多源数据分析场景的自动化分析系统，自动处理银行账单、微信账单、支付宝账单和话单数据，生成结构化的 Excel 详表 + Word 解读式分析报告。新增 AI 协同层后，可将规则引擎发现的异常、模式、风险自动转写为自然语言叙事和可验证假设。

## 重构说明

本项目是对旧版多源数据分析系统的全面重构（`datadone` → `datadone-re`），重构方案基于 [**本质探索 Skill**](https://github.com/zh2673-git/essence-programming) 进行纯逻辑推理形成。

### 方法论：本质探索

> 本质探索是一种基于"三阶方法论"的认知框架，核心思想是**从本质逻辑推导设计，而非从经验归纳设计**。

**三阶方法论** — 每个主题按坡度渐进展开：

```
是什么（定义本质）→ 为什么（建立因果）→ 怎么做（推导方案）
   ↓                   ↓                   ↓
 阶段1: 点出概念    阶段1: 点出概念     阶段1: 点出概念
 阶段2: 建立联系    阶段2: 建立联系     阶段2: 建立联系
 阶段3: 详细解释    阶段3: 详细解释     阶段3: 详细解释
```

**核心特色**：
- **坡度理解**：先抽象后具体，先骨架后血肉，认知逐层加深
- **纯逻辑推理**：不依赖经验假设，从约束条件出发逐步推导必然结论
- **约束驱动**：边界条件（如"仅有四类数据"）成为推导的起点而非限制
- **因果闭环验证**：每个环节的必要性通过"缺少它会怎样"来验证

### 分析逻辑的推导过程

本次重构的核心——**分析引擎六层递进逻辑**，就是通过本质探索推导出来的：

```
约束：仅有银行、微信、支付宝、话单四类数据，无任何外部信息

推导链：
  没有外部参照 → 只能用自身历史作参照 → 自我基线（第2层）
  有了基线 → 才能判定什么是"异常" → 异常识别（第3层）
  异常不是随机分布 → 特定异常组合指向特定模式 → 行为模式归类（第4层）
  孤立异常不构成证据 → 多源交叉验证构建因果 → 时序因果链（第5层）
  大量分析结果散落 → 决策者无法快速判断 → 风险研判（第6层）
```

**关键洞察**：从"绝对异常"到"相对异常"的转变——在没有外部基准时，被核查人自身的历史行为就是唯一的参照系。偏离自身历史基线的行为即为相对异常，这恰好符合线索级分析"发现需要进一步核查的线索"的定位。

### 旧版问题与重构目标

**旧版问题：**

| 问题 | 说明 |
|------|------|
| 导出器过于庞大 | 单文件承载过多逻辑（`excel_exporter.py` 117KB、`word_exporter_new.py` 133KB），违反单一职责 |
| 分析与导出耦合 | 分析逻辑散落在 analyzer 和 exporter 中，难以独立测试和复用 |
| 数据模型配置耦合 | 数据模型初始化时从 config 读取 30+ 字段，模型与配置紧耦合 |
| 状态管理混乱 | 分析结果通过 dict 传递，无统一状态源 |
| 类型定义缺失 | 全部使用 dict/DataFrame 传递数据，缺少数据规矩，运行时才能发现错误 |
| CLI 与业务混合 | CLI 中包含数据处理逻辑，界面与业务耦合 |

**重构目标：**

1. **解耦导出与分析** — 分析结果生成结构化数据对象，导出器只负责格式化输出
2. **统一状态管理** — 引入全局状态对象，所有模块通过接口契约读写
3. **类型安全** — 使用 Pydantic V2 定义数据规矩，运行时自动验证
4. **模块自治** — 每个模块内部状态自治，对外暴露统一接口
5. **保持输出一致** — 重构后的导出报告与现有输出完全一致

**核心架构变更：**

```
旧版：单体脚本式 → dict/DataFrame 传递 → 分析与导出耦合
新版：分层模块化 → Pydantic 数据规矩 → 状态对象 + 方法编排 → 分析与导出解耦
```

四层基础设施：**数据规矩（Pydantic V2） → 数据存储（DataFrame + Pydantic） → 数据流转（状态对象 + 方法编排） → 接口层（Protocol + 数据类）**

## 功能特性

- **多源数据加载**：支持银行、微信、支付宝、话单四种数据源，自动识别文件类型
- **智能文件夹扫描**：递归扫描 `data/` 目录，自动识别人物文件夹及其中数据文件
- **批量分析**：多人独立分析，每人生成独立报告
- **合并分析**：多人数据合并统一分析，发现跨人员资金往来关系
- **全维度分析引擎**：
  - 频率分析（交易对手统计）
  - 存取现识别（大额/同日/连续取现标记）
  - 特殊金额检测（爱情数字/吉利数字/规避阈值）
  - 特殊日期交易（节假日大额）
  - 综合交叉分析（通话+资金双平台交叉）
  - 行为基线与异常检测（σ偏离度）
  - 行为模式识别（周期性收入/资金中转/规避检测）
  - 时序链发现（通话→资金关联证据链）
  - 风险研判（四维度评分+调查建议）
  - 习惯兴趣识别（关键词+商户模式+频率统计，三级习惯等级判定）
  - **AI 协同层（可选）**：基于规则信号生成人员级叙事、线索级叙事、调查假设，并注入 Excel/Word 报告

## AI 协同层（可选）

`v1.1.0` 新增了一层可开关的 AI 协同能力，定位为**规则引擎的增强层**：

- **只做翻译，不做判断**：输入是规则引擎已识别的异常、行为模式、时序链、风险研判等结构化信号，由 LLM 输出自然语言叙事和可验证假设；
- **三段输出**：人员级叙事、线索级叙事、调查假设，每个假设都附带具体验证方向；
- **符号校验**：每条 AI 结论必须标注可追溯的证据 ID，防止幻觉；
- **失败降级**：AI 层故障不影响核心规则分析和报告导出；
- **多模型支持**：内置 OpenAI、Ollama 本地模型、Mock 三种 Provider；
- **报告增强**：Excel 新增"AI 摘要"工作表，Word 新增"（AI）智能解读与调查提示"章节。

默认关闭，可通过 `config/config.json` 中 `ai.enabled` 开启，或在代码中显式构造 `Application(ai_enabled=True)`。

## 快速开始

### 安装依赖

```bash
pip install -e .
```

需要 Python ≥ 3.10。

### 数据准备

将数据文件放入 `data/` 目录，支持两种组织方式：

**方式一：多人物文件夹（推荐）**

```
data/
  某项目分类汇总/
    张三/
      张三账单数据预览.xlsx    ← 银行（文件名含"账单/银行/流水"）
      张三微信账单浏览.xlsx    ← 微信（文件名含"微信"）
      话单数据预览.xlsx        ← 话单（文件名含"话单/通话"）
    李四/
      ...
```

**方式二：单文件模式**

```
data/
  银行账单.xlsx
  微信账单.xlsx
  话单数据.xlsx
```

### 运行

```bash
python main.py
```

交互式菜单会自动识别数据组织方式：

```
============================================================
  多源数据分析系统
============================================================

[已识别 5 个人物文件夹]
  1. 张三 (bank/wechat/call)
  2. 李四 (bank/wechat/call)
  ...

请选择操作：
  1. 选择人员并批量分析（推荐）
  2. 全部人员批量分析
  3. 合并分析（所有人放一起分析，生成统一报告）
  4. 加载数据（手动指定文件）
  5. 执行分析
  6. 导出报告
  7. 一键运行（单人模式）
  8. 退出
```

## 报告输出

分析完成后在 `output/` 目录生成两种格式报告：

output/

  合并分析/
    分析报告.xlsx

### Excel 报告（12个工作表）

| 工作表 | 内容 |
|--------|------|
| **分析汇总表** | 每人每平台收支汇总（存现/取现/转账分类） |
| **存取现明细表** | 逐笔存取现记录，含大额标记(★)、同日存取/连续取现备注 |
| **重点收支明细表** | 重点收支+特殊金额+特殊日期+规避阈值交易，按类型着色 |
| **账单类频率表** | 交易对手收支统计，含收入/支出占比 |
| **话单类频率表** | 通话频率统计，含对方单位、特殊时间通话 |
| **综合分析表** | 跨平台交叉分析，标注交叉类型（双平台交叉/仅账单/仅话单） |
| **大额资金跟踪表** | 大额资金流向逐笔跟踪，含通话关联 |
| **异常明细表** | 异常行为逐条记录，含偏离度、严重程度、基线对比 |
| **行为发现表** | 行为模式+时序链合并呈现，含匹配度、关键证据 |
| **风险研判表** | 行为基线指标+四维度风险评分+调查建议 |
| **习惯兴趣表** | 习惯兴趣识别结果，含习惯等级着色（高频习惯绿/低频偏好蓝/偶尔消费灰） |
| **AI 摘要表** | AI 协同层生成的叙事块与调查假设（AI 开启时输出） |

**Excel 条件格式示例：**

| 列 | 着色规则 |
|----|----------|
| 交易金额 | ≥5万整行红色高亮 |
| 大额标记 | ★行橙色高亮 |
| 存取现标识 | 存现/取现黄色高亮 |
| 综合风险等级 | 高风险红/中风险黄/低风险绿 |
| 严重程度 | 高红色/中黄色 |
| 交叉类型 | 双平台交叉绿色高亮 |
| 重点类型 | 规避阈值红/特殊金额绿/特殊日期蓝/工作收入浅绿 |

## 配置说明

- `config/keywords.json`：关键词库，定义重点收支匹配关键词（工资/租金/房产等）、行为模式关键词、习惯兴趣类别关键词（12类：餐饮/健身/游戏/旅行/宠物/烟酒/教育/医疗/美容/数码/服饰/居住）
- `config/thresholds.json`：阈值配置，包括大额交易阈值、偏离度阈值、风险评分权重等
- `config/config.json`：基础配置，包含数据源字段映射、`ai.enabled` 等 AI 协同层开关
