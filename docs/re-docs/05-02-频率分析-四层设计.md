> 所属模块：分析引擎 | 实现位置：`src/analysis/frequency.py`

## 模块内部状态

```python
from pydantic import BaseModel
from typing import Optional

class FrequencyItem(BaseModel):
    """账单类频率分析结果"""
    platform: str                   # 平台名
    data_source: str                # 数据来源文件名
    本方姓名: str
    对方姓名: str
    收入总额: float
    支出总额: float
    交易次数: int
    交易总金额: float
    交易时间跨度: Optional[int]     # 天数

class CallFrequencyItem(BaseModel):
    """话单频率分析结果"""
    platform: str                   # 固定"话单"
    data_source: str
    本方姓名: str
    对方姓名: str
    对方号码: str
    对方单位名称: Optional[str]
    对方职务: Optional[str]
    通话次数: int
    主叫次数: int
    被叫次数: int
    通话总时长秒: float
    通话总时长分钟: float
    通话占比: Optional[str]         # 百分比字符串
    特殊时间次数: int
```

## 四层设计

| 层面 | 设计内容 |
|-----|---------|
| **数据规矩** | `FrequencyItem`(Pydantic)：账单频率，含平台/姓名/金额/次数/时间跨度；`CallFrequencyItem`(Pydantic)：话单频率，含通话次数/时长/主被叫/占比 |
| **数据存储** | 账单频率存入 `AnalysisResult.frequency`（{平台: [结果]}）；话单频率存入 `AnalysisResult.call_frequency`（List） |
| **数据流转** | 账单数据：按(本方姓名, 对方姓名, 平台)分组聚合收入/支出/次数；话单数据：按(本方姓名, 对方姓名, 对方号码)分组聚合通话次数/时长/主被叫。仅统计转账记录（排除存取现） |

**频率分析流转图**：

```mermaid
stateDiagram-v2
    [*] --> 数据分流
    数据分流 --> 账单频率: 银行/微信/支付宝
    数据流向 --> 话单频率: 话单数据

    state 账单频率 {
        [*] --> 筛选转账记录: 排除存取现
        筛选转账记录 --> 按对方分组: (本方, 对方, 平台)
        按对方分组 --> 聚合计算: 收入总额/支出总额/次数/时间跨度
    }

    state 话单频率 {
        [*] --> 按通话对方分组: (本方, 对方, 号码)
        按通话对方分组 --> 通话聚合: 次数/时长/主被叫
        通话聚合 --> 特殊时间统计: 非工作时间通话
    }

    账单频率 --> [*]: List[FrequencyItem]
    话单频率 --> [*]: List[CallFrequencyItem]
``` 账单：筛选转账记录 → 按(本方,对方)分组聚合 → 排序；话单：按(本方,对方,对方号码)分组聚合 → 计算占比 |
| **接口层** | `FrequencyAnalyzer.analyze(all_data, config) → Dict[str, List[FrequencyItem]]`；`FrequencyAnalyzer.analyze_calls(call_data, config) → List[CallFrequencyItem]` |

## 精确算法规则

### 账单类频率分析

**数据范围**：`存取现标识 == '转账'` 的记录

**分组键**：`[本方姓名, 对方姓名]`

**聚合规则**：
- `收入总额` = SUM(收入金额)
- `支出总额` = SUM(支出金额)
- `交易次数` = COUNT(交易日期)
- `交易总金额` = 收入总额 + 支出总额
- `交易时间跨度` = (MAX(交易日期) - MIN(交易日期)).days + 1

**排序**：`本方姓名 ASC, 交易总金额 DESC`

**标准化（导出时）**：
- `收入占比` = `收入总额 / 全表收入总额 * 100`（保留2位小数，带%号）
- `支出占比` = `支出总额 / 全表支出总额 * 100`（保留2位小数，带%号）

---

### 话单频率分析

**分组键**：`[本方姓名, 对方姓名, 对方号码]`

**聚合规则**：
- `通话次数` = COUNT(*)
- `主叫次数` = COUNT(呼叫类型 == '主叫')
- `被叫次数` = COUNT(呼叫类型 == '被叫')
- `通话总时长(秒)` = SUM(通话时长)
- `通话总时长(分钟)` = 通话总时长(秒) / 60
- `通话占比` = `通话次数 / 全表通话次数 * 100`

**特殊时间次数**：在特殊日期（见 [[05-04-特殊分析-四层设计]]）内的通话次数
