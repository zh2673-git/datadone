## 一、是什么（坡度三阶段）

### 阶段1：点出概念

> **一句话定义**：资金基线是"钱多钱少的正常值"——量化被核查人月均收支多少、单笔多大、对手多少，构成判断"资金异常"的参照原点。

**本质特征**：

| 推导要素 | 逻辑分析 | 结论 |
|---------|---------|------|
| **统计对象** | 资金基线度量什么？ | 金额（收支总额/单笔/分位数）+ 频次（月均笔数）+ 对手数（月均人数） |
| **时间粒度** | 资金行为以什么粒度统计？ | 月度粒度——与初核关注的"月度收支异常"匹配 |
| **分布特征** | 资金基线是什么形态？ | 通常右偏分布（多数月份中等，少数月份极高）→ 用中位数+均值双重描述 |

### 阶段2：建立联系

| 属性名 | 类型 | 说明 | 深入？ |
|-------|-----|-----|-------|
| **月度收支基线** | 属性 | 月收入/支出的均值+标准差 | ❌ 当前文档说明 |
| **单笔金额分布** | 属性 | 均值/中位数/P25/P75 | ❌ 当前文档说明 |
| **对手数量基线** | 属性 | 月均交易对手数+标准差 | ❌ 当前文档说明 |
| **平台分布基线** | 属性 | 各平台收支占比 | ❌ 当前文档说明 |

### 阶段3：详细解释

**月度收支基线**
- **定义**：被核查人每月收入/支出的正常范围
- **计算**：按年月汇总 → 均值 ± 标准差
- **特殊处理**：
  - 数据首月和末月可能不完整 → 按实际天数折算
  - 季节性因素（如年底集中发奖金）→ 标注"含季节性波动"
  - 单月极端值（>3σ）→ 排除后重新计算"修正基线"

**单笔金额分布**
- **定义**：单笔交易金额的统计分布
- **关键点**：
  - 通常右偏：大量小额+少量大额 → 均值>中位数
  - P25/P75定义"正常金额区间"：P25以下为小额，P75以上为大额
  - 初核意义：单笔>基线P75的新对手 → 值得关注

**对手数量基线**
- **定义**：月均交易对手数的正常范围
- **关键点**：月均对手数+标准差 → 某月对手数突增→"关系网扩展"信号

**平台分布基线**
- **定义**：各平台交易金额的占比
- **关键点**：如果某人平时银行占80%，突然微信占60% → 平台迁移信号

## 二、为什么（坡度三阶段）

### 阶段1：点出概念

> **一句话总结**：资金基线是所有异常判定的第一参照——"月支出偏离基线4倍"比"月支出50万"更有判断价值。

### 阶段2：建立联系

| 因果 | 因 | 果 | 逻辑 | 类比 |
|-----|---|---|-----|------|
| **有基线才有相对判断** | 知道月均5万 | 月50万=偏离10倍 | 有标尺才能度量 | 知道正常体温才能判断发烧 |
| **分布形态决定判定方法** | 资金数据右偏 | 用中位数比均值更稳健 | 抗极端值 | 收入统计用中位数比平均数更准 |
| **多维度基线互验证** | 收支+对手+平台 | 单维度异常+其他维度也异常→更可信 | 交叉验证 | 血压+心率都异常→更值得关注 |

## 三、怎么做（坡度三阶段）

### 阶段1：点出概念

> **一句话概述**：合并三平台数据→按月聚合→统计均值/标准差/分位数→输出资金基线对象。

### 阶段2：建立联系

| 步骤 | 动作 | 产出 | 注意事项 |
|-----|------|------|---------|
| **1.合并三平台** | concat银行+微信+支付宝 | 统一DataFrame | 附加平台来源列 |
| **2.按月聚合** | groupby(年月)计算收入/支出/对手数 | 月度指标 | 处理不完整月份 |
| **3.统计基线** | mean/std/median/quantile | 基线数值 | 排除极端月(>3σ)后重算修正基线 |
| **4.趋势计算** | 线性回归 | 趋势方向 | ≥4个月数据才计算 |

### 阶段3：详细解释

```python
def compute_fund_baseline(person_df: pd.DataFrame) -> FundBaseline:
    """计算资金基线"""
    df = person_df.copy()
    df['年月'] = pd.to_datetime(df['交易日期']).dt.to_period('M')
    
    monthly = df.groupby('年月').agg(
        收入=('收入金额', 'sum'),
        支出=('支出金额', 'sum'),
        交易次数=('交易金额', 'count'),
        对手数=('对方姓名', 'nunique'),
    ).reset_index()
    
    # 排除极端月份后计算修正基线
    for col in ['收入', '支出']:
        mean = monthly[col].mean()
        std = monthly[col].std()
        if std > 0:
            normal = monthly[abs(monthly[col] - mean) / std <= 3]
            monthly[f'{col}_修正均值'] = normal[col].mean()
            monthly[f'{col}_修正标准差'] = normal[col].std()
    
    # 单笔金额分布
    amounts = df['交易金额'].abs()
    amount_dist = {
        '均值': amounts.mean(),
        '中位数': amounts.median(),
        'P25': amounts.quantile(0.25),
        'P75': amounts.quantile(0.75),
        'P95': amounts.quantile(0.95),
    }
    
    return FundBaseline(
        月均收入=monthly['收入'].mean(),
        月均收入_std=monthly['收入'].std(),
        月均支出=monthly['支出'].mean(),
        月均支出_std=monthly['支出'].std(),
        月均交易次数=monthly['交易次数'].mean(),
        月均对手数=monthly['对手数'].mean(),
        单笔金额分布=amount_dist,
        月度明细=monthly.to_dict('records'),
    )
```
