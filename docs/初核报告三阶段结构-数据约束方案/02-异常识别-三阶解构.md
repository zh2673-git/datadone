## 一、是什么（坡度三阶段）

### 阶段1：点出概念

> **一句话定义**：异常识别是"偏离探测器"——将每个行为指标与自我基线对比，找出统计上显著偏离的事件、时段、对手，标记为需要关注的风险信号。

**本质特征**：

| 推导要素 | 逻辑分析 | 结论 |
|---------|---------|------|
| **输入** | 异常识别的前提是什么？ | 自我基线（正常值）+ 当前行为（观测值） |
| **输出** | 异常识别的结果是什么？ | 异常事件列表，每个异常附带偏离度和方向 |
| **判定逻辑** | 什么算异常？ | 偏离基线超过N个标准差（默认2σ，可配置） |
| **分类** | 异常有几种类型？ | 6类：资金异常/时间异常/频率异常/金额异常/对手异常/行为异常 |

### 阶段2：建立联系

| 属性名 | 类型 | 说明 | 深入？ |
|-------|-----|-----|-------|
| **资金异常** | 子模块 | 月度/单笔收支偏离基线 | ✅ 需深入 → [[02-01-资金异常-三阶解构]] |
| **时间异常** | 子模块 | 非正常时段交易/通话 | ✅ 需深入 → [[02-02-时间异常-三阶解构]] |
| **频率异常** | 子模块 | 交易/通话频率偏离 | ✅ 需深入 → [[02-03-频率异常-三阶解构]] |
| **金额异常** | 属性 | 金额特征偏离（Z-score/整数偏好变化） | ❌ 当前文档说明 |
| **对手异常** | 属性 | 新对手/消失对手/对手突变 | ❌ 当前文档说明 |
| **行为异常** | 属性 | 规避行为/拆分行为/集中行为 | ❌ 当前文档说明 |

### 阶段3：详细解释

**金额异常**
- **定义**：单笔交易金额显著偏离个人历史金额分布
- **关键点**：
  - 当前项目 `AdvancedAnalyzer._detect_anomalies` 已有Z-score检测（>3σ）
  - 需升级：附加偏离度数值 + 具体交易明细 + 涉及对手
  - 新增"整数偏好变化"：如果某人平时整百占比30%，突然某月整百占比80% → 偏离

**对手异常**
- **定义**：交易对手模式偏离历史基线
- **关键点**：
  - **新对手异常**：首次出现且单笔金额>基线P75 → 标记"异常新对手"
  - **消失对手异常**：曾经频繁交易(>5次/月)的对手突然消失 → 标记"关系断裂"
  - **对手集中度异常**：某月TOP1对手交易占比>50%（基线为20%）→ 偏离2.5倍

**行为异常**
- **定义**：行为模式偏离历史基线
- **关键点**：
  - **规避行为**：4-5万区间密集交易（疑似规避5万大额报告阈值）
  - **拆分行为**：同对手短期内(7天)多笔等额交易(±5%)
  - **集中行为**：某日/某周交易量偏离日/周均值的3倍以上

## 二、为什么（坡度三阶段）

### 阶段1：点出概念

> **一句话总结**：异常识别是"基线的另一半"——基线定义了"正常"，异常识别定义了"不正常"，二者合一才能回答"什么需要关注"。

### 阶段2：建立联系

| 因果 | 因 | 果 | 逻辑 | 类比 |
|-----|---|---|-----|------|
| **基线→异常** | 有了"正常"的量化定义 | 才能量化"异常"的程度 | 有正常值才能诊断 | 有血压正常值才能诊断高血压 |
| **异常→模式** | 单个异常可能是偶发 | 多个异常的组合指向行为模式 | 多个症状组合→疾病 | 头痛+发烧+咳嗽→感冒 |
| **偏离度→严重性** | 偏离1σ vs 偏离4σ | 严重程度完全不同 | 偏离越大越值得关注 | 血压140 vs 血压200 |
| **方向性** | 收入突增 vs 支出突增 | 指向不同问题类型 | 异常方向决定分析方向 | 体温升高vs降低指向不同疾病 |

### 阶段3：详细解释

**当前项目的异常识别 vs 升级后的对比**：

| 维度 | 当前项目 | 升级后 |
|-----|---------|-------|
| **参照系** | 无参照（孤立判断） | 以自我基线为参照 |
| **偏离度** | 无偏离度概念 | 每个异常附加"偏离基线X倍" |
| **异常类型** | 4类（存取现/特殊金额/特殊日期/Z-score） | 6类（+时间异常/对手异常/行为异常） |
| **结果描述** | "有N笔金额异常" | "有N笔金额异常，偏离基线4.2倍，涉及对手张三" |
| **可操作性** | 低（需人工判断是否真的异常） | 高（有偏离度量化，直接判断严重程度） |

## 三、怎么做（坡度三阶段）

### 阶段1：点出概念

> **一句话概述**：对每个行为维度，用当前值减去基线均值再除以基线标准差，得到偏离倍数（σ），超过阈值则标记为异常并记录。

### 阶段2：建立联系

| 步骤 | 动作 | 产出 | 注意事项 |
|-----|------|------|---------|
| **1.月度对比** | 逐月比较收支与基线 | 偏离月份列表 | 用基线的均值±2σ判定 |
| **2.单笔扫描** | 逐笔检查金额/时间/对手 | 异常交易标记 | 附加偏离度数值 |
| **3.模式检测** | 检测规避/拆分/集中行为 | 行为异常标记 | 这类异常不依赖基线，依赖规则 |
| **4.对手扫描** | 检测新对手/消失对手 | 对手异常标记 | 需要按月对手列表做对比 |
| **5.汇总输出** | 合并所有异常，按严重度排序 | AnomalyResult | 每个异常含：类型/偏离度/涉及对手/时间/金额 |

### 阶段3：详细解释

**异常结果数据模型**：

```python
@dataclass
class AnomalyItem:
    """单个异常项"""
    异常类型: str       # 资金异常/时间异常/频率异常/金额异常/对手异常/行为异常
    异常子类: str       # 月度收入突增/深夜交易/规避行为/...
    偏离度: float       # 偏离基线的σ倍数（行为异常用-1标记）
    严重程度: str       # 高(>3σ)/中(2-3σ)/低(<2σ但规则触发)
    本方姓名: str
    对方姓名: str       # 可能空
    交易日期: str
    交易金额: float
    基线均值: float     # 对比的基线值
    说明: str           # "月收入50万，偏离基线均值12万4.2σ"
```

**规避行为检测算法**：

```python
def detect_avoidance(df: pd.DataFrame, threshold=50000, window=0.8, min_count=3):
    """
    规避行为检测：
    1. 阈值附近密集交易：金额在 [threshold*window, threshold) 区间内≥min_count笔
    2. 等额拆分：同一对手7天内≥2笔金额差异<5%的交易
    """
    anomalies = []
    
    # 检测1：阈值附近密集交易
    near = df[(df['交易金额'].abs() >= threshold * window) & 
              (df['交易金额'].abs() < threshold)]
    if len(near) >= min_count:
        anomalies.append({
            '异常子类': '阈值附近密集交易',
            '说明': f'在{threshold*window/10000:.0f}-{threshold/10000:.0f}万区间有{len(near)}笔交易，疑似规避大额报告',
            '涉及金额': near['交易金额'].abs().sum(),
        })
    
    # 检测2：等额拆分
    for opponent, group in df.groupby('对方姓名'):
        if not opponent or len(group) < 2:
            continue
        sorted_group = group.sort_values('交易日期')
        for i in range(len(sorted_group) - 1):
            row1 = sorted_group.iloc[i]
            row2 = sorted_group.iloc[i + 1]
            time_gap = (pd.to_datetime(row2['交易日期']) - pd.to_datetime(row1['交易日期'])).days
            if time_gap <= 7:
                amt1, amt2 = abs(row1['交易金额']), abs(row2['交易金额'])
                if amt1 > 0 and amt2 > 0 and abs(amt1 - amt2) / max(amt1, amt2) < 0.05:
                    anomalies.append({
                        '异常子类': '等额拆分交易',
                        '说明': f'与{opponent}在{time_gap}天内有两笔金额相近交易({amt1:.0f}/{amt2:.0f})',
                    })
    
    return anomalies
```

**验证方法**：
- 检查点1：异常项的偏离度计算是否正确（手动验证1-2个案例）
- 检查点2：基线均值为0时不会除零
- 检查点3：规避行为检测结果有明确规则支撑
