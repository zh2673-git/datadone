## 一、是什么（坡度三阶段）

### 阶段1：点出概念

> **一句话定义**：异常量化是"问题度量衡"——将"有异常"升级为"异常有多大"，用偏离倍数、涉及金额、涉及人数、时间密度等指标量化问题的严重程度。

**本质特征**：

| 推导要素 | 逻辑分析 | 结论 |
|---------|---------|------|
| **核心问题** | "有异常"不够用，还需要什么？ | 需要知道"多异常"——异常的严重程度决定优先级 |
| **量化维度** | 严重程度由什么决定？ | 4个维度：偏离程度、涉及规模、持续时间、涉及人员 |
| **与异常识别的关系** | 异常量化与异常识别有何区别？ | 异常识别回答"有没有"，异常量化回答"有多大"——是识别后的深化 |

### 阶段2：建立联系

| 属性名 | 类型 | 说明 | 深入？ |
|-------|-----|-----|-------|
| **偏离度量化** | 子模块 | σ倍数/基线倍数/百分位排名 | ✅ 需深入 |
| **规模量化** | 属性 | 涉及金额/涉及交易数/涉及人数 | ❌ 当前文档说明 |
| **时间量化** | 属性 | 持续月数/时间密度/是否持续中 | ❌ 当前文档说明 |
| **综合评分** | 属性 | 多维度加权汇总为单一分数 | ❌ 当前文档说明 |

### 阶段3：详细解释

**规模量化**
- **定义**：异常涉及的资金和人员规模
- **关键点**：
  - 涉及金额 = 所有异常交易的金额汇总
  - 涉及交易数 = 异常交易笔数
  - 涉及人数 = 异常交易涉及的唯一对手数
  - **分级**：金额<10万(小)/10-100万(中)/100-1000万(大)/>1000万(巨大)

**时间量化**
- **定义**：异常持续的时间特征
- **关键点**：
  - 持续月数 = 异常最早月份到最晚月份的跨度
  - 时间密度 = 异常交易数 / 持续月数（每月异常次数）
  - 是否持续中 = 最近1个月是否仍有异常
  - **分类**：偶发(1个月)/短期(2-3个月)/持续(>3个月)

**综合评分**
- **定义**：将偏离度+规模+时间三个维度加权为0-100的综合异常分数
- **关键点**：
  - 偏离度权重40%：反映异常的统计显著性
  - 规模权重35%：反映异常的现实影响
  - 时间权重25%：反映异常的持续性和系统性
  - 综合分≥70为"高度异常"，40-69为"中度异常"，<40为"轻度异常"

## 二、为什么（坡度三阶段）

### 阶段1：点出概念

> **一句话总结**：异常量化是"从定性到定量的关键一步"——没有量化，就无法排序优先级，无法判断哪些异常值得优先追查。

### 阶段2：建立联系

| 因果 | 因 | 果 | 逻辑 | 类比 |
|-----|---|---|-----|------|
| **量化才能排序** | 50个异常无法人工逐一追查 | 需要按严重程度排序 | 分诊制度 | 急诊按病情轻重排序 |
| **量化才能决策** | "异常"≠"需要立案" | 需要量化严重程度判断是否达到立案标准 | 诊断标准 | 血压140可能观察，200必须治疗 |
| **量化才能追踪** | 异常可能随时间变化 | 需要量化指标跟踪变化趋势 | 复查指标 | 血压降了还是升了 |
| **量化才能比较** | 不同人的异常需要横向比较 | 需要统一的量化标准 | 评分系统 | 不同考生用同一套卷子评分 |

### 阶段3：详细解释

**偏离度量化方法论**：

| 量化方法 | 适用场景 | 计算方式 | 优点 | 局限 |
|---------|---------|---------|------|------|
| **σ倍数** | 正态分布数据 | (观测值-均值)/标准差 | 统计学标准，可比 | 假设正态分布 |
| **基线倍数** | 收支金额类 | 观测值/基线均值 | 直观易懂 | 基线为0时失效 |
| **百分位排名** | 金额分布 | 该值在历史数据中的排名 | 鲁棒，不受极端值影响 | 不反映绝对差距 |

**选择**：三种方法并行使用，互为补充：
- σ倍数用于统计报告
- 基线倍数用于直观呈现（"月支出是平时的4.2倍"）
- 百分位排名用于金额定位（"该金额超过历史99%的交易"）

## 三、怎么做（坡度三阶段）

### 阶段1：点出概念

> **一句话概述**：对每个异常项计算偏离度(σ倍数)、涉及规模(金额/人数)、持续时间，加权汇总为综合异常分数。

### 阶段2：建立联系

| 步骤 | 动作 | 产出 | 注意事项 |
|-----|------|------|---------|
| **1.偏离度计算** | 对每个异常项计算σ倍数/基线倍数/百分位 | 量化偏离度 | 基线为0时特殊处理 |
| **2.规模计算** | 汇总异常涉及的金额/交易数/人数 | 量化规模 | 区分单笔最大和累计总额 |
| **3.时间计算** | 计算异常持续月数和密度 | 量化时间特征 | 区分偶发和持续 |
| **4.综合评分** | 三维度加权 → 0-100分 | 综合异常分数 | 权重可配置 |
| **5.分级** | 按分数划分为高/中/低 | 异常等级 | 阈值可配置 |

### 阶段3：详细解释

**量化结果数据模型**：

```python
@dataclass
class QuantifiedAnomaly:
    """量化后的异常"""
    # 偏离度
    sigma倍数: float          # (观测值-基线均值)/基线标准差
    基线倍数: float           # 观测值/基线均值（基线为0时为inf）
    百分位排名: float         # 在历史数据中的百分位
    
    # 规模
    涉及金额: float           # 异常交易总金额
    单笔最大金额: float
    涉及交易数: int
    涉及人数: int
    规模等级: str             # 小/中/大/巨大
    
    # 时间
    持续月数: int
    时间密度: float           # 异常交易数/持续月数
    是否持续中: bool
    时间分类: str             # 偶发/短期/持续
    
    # 综合
    综合异常分数: float       # 0-100
    异常等级: str             # 高度/中度/轻度
```

**综合评分公式**：

```
综合异常分数 = 
    偏离度得分(0-40) + 规模得分(0-35) + 时间得分(0-25)

其中：
  偏离度得分 = min(σ倍数/5, 1) × 40    （5σ以上满分）
  规模得分   = 规模等级映射{小:5, 中:15, 大:25, 巨大:35}
  时间得分   = 时间分类映射{偶发:5, 短期:15, 持续:25}
```

**验证方法**：
- 检查点1：综合分数在0-100范围内
- 检查点2：σ倍数为2时，偏离度得分=16（= 2/5×40）
- 检查点3：基线为0时基线倍数标为"∞"而非报错
