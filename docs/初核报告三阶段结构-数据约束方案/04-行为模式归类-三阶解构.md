## 一、是什么（坡度三阶段）

### 阶段1：点出概念

> **一句话定义**：行为模式归类是"异常的拼图"——将零散的异常信号按规则组合为有意义的模式，从"这笔交易异常"升级为"这组异常构成周期性收入模式"。

**本质特征**：

| 推导要素 | 逻辑分析 | 结论 |
|---------|---------|------|
| **输入** | 模式归类的前提是什么？ | 异常识别结果 + 原始数据 + 基线 |
| **输出** | 模式归类的结果是什么？ | 匹配到的行为模式列表，每个模式含匹配度+关键证据 |
| **判定逻辑** | 如何判断异常组合构成某种模式？ | 规则匹配——预定义模式的识别条件，全部满足则匹配 |
| **边界** | 模式归类能做什么/不能做什么？ | 能描述行为特征，不能做法律定性 |

### 阶段2：建立联系

5种可识别的行为模式（四类数据约束下）：

| 模式 | 识别特征 | 深入？ |
|-----|---------|-------|
| **P1 周期性收入模式** | 特定对手≥3月定期收入 | ✅ 需深入 → [[04-01-P1周期性收入-三阶解构]] |
| **P2 资金中转模式** | 大额转入后48h内取现/转出≥60% | ✅ 需深入 → [[04-02-P2资金中转-三阶解构]] |
| **P3 通讯-资金关联模式** | 通话后24h内与通话对手资金往来≥3次 | ✅ 需深入 → [[04-03-P3通讯资金关联-三阶解构]] |
| **P4 规避检测模式** | 阈值附近密集交易/等额拆分 | ❌ 当前文档说明 |
| **P5 特殊关系模式** | 特殊金额+特殊日期+深夜通话组合 | ❌ 当前文档说明 |

### 阶段3：详细解释

**P4 规避检测模式**
- **定义**：疑似故意规避大额交易报告阈值的行为
- **关键识别规则**：
  - 条件1：4-5万区间交易≥3笔（疑似规避5万阈值）
  - 条件2：同一对手7天内≥2笔金额差异<5%的交易（疑似拆分）
  - 条件3：单日同对手多笔交易合计>5万但单笔均<5万（疑似日拆分）
  - 匹配度计算：满足1个条件=60%，2个=80%，3个=95%
- **报告用语**："存在疑似规避大额交易报告特征"

**P5 特殊关系模式**
- **定义**：超出正常社交/商业关系的特殊个人关系指向
- **关键识别规则**：
  - 条件1：特殊金额(520/1314/3344等)交易≥2笔
  - 条件2：特殊日期(情人节/七夕/生日推测)交易≥1笔
  - 条件3：深夜(22-6点)通话≥3次
  - 匹配度计算：满足2个条件=60%，3个=85%
- **报告用语**："存在特殊关系资金往来特征"

## 二、为什么（坡度三阶段）

### 阶段1：点出概念

> **一句话总结**：模式归类是"从症状到综合征"——孤立的异常事件意义有限，但特定组合的异常构成模式后，就具有了方向性指向价值。

### 阶段2：建立联系

| 因果 | 因 | 果 | 逻辑 | 类比 |
|-----|---|---|-----|------|
| **孤立异常无方向** | 单个异常可能是巧合 | 无法判断指向什么问题 | 单一症状无法确诊 | 只发烧不能确定什么病 |
| **模式有方向** | 特定异常组合指向特定行为 | 提供调查方向 | 症状群→疾病类型 | 发烧+咳嗽+胸痛→肺炎 |
| **模式有匹配度** | 不是非黑即白 | 匹配度反映模式的确定程度 | 概率诊断 | 80%可能是肺炎 |
| **报告用语限制** | 数据只能证明行为特征 | 不能做法律定性 | 证据链不完整 | 只能说"疑似"，不能说"确诊" |

### 阶段3：详细解释

**模式匹配的核心理念：规则匹配 + 匹配度评分**

为什么不用机器学习：
1. **可解释性**：初核报告必须说清"为什么判定这个模式"，规则匹配天然可解释
2. **数据不足**：没有标注的违纪违法数据集，无法训练模型
3. **可配置性**：规则可通过配置文件调整，无需重新训练
4. **可审计性**：每条规则可追溯到具体法规/实务经验

**匹配度的本质**：
- 匹配度 ≠ 概率（不是"P(权钱交易)=80%"）
- 匹配度 = 条件满足度（"识别该模式所需条件的满足程度"）
- 匹配度80%意味着：5个条件中4个满足，还有1个未满足

## 三、怎么做（坡度三阶段）

### 阶段1：点出概念

> **一句话概述**：对每个人，逐个检查5种模式的识别条件是否满足，计算匹配度，输出匹配到的模式列表。

### 阶段2：建立联系

| 步骤 | 动作 | 产出 | 注意事项 |
|-----|------|------|---------|
| **1.输入准备** | 收集异常识别结果+原始数据+基线 | 输入数据集 | 确保异常已附加偏离度 |
| **2.逐模式检查** | 对P1-P5逐一检查识别条件 | 每个模式的匹配结果 | 每个条件标记满足/不满足 |
| **3.匹配度计算** | 根据满足条件数计算匹配度 | 匹配度(0-100%) | 不满足关键条件则直接为0% |
| **4.证据提取** | 为匹配到的模式提取关键证据 | 证据列表 | 证据需可追溯到具体交易/通话 |
| **5.输出** | 生成PatternMatch列表 | 模式识别结果 | 同一人可匹配多个模式 |

### 阶段3：详细解释

**P1 周期性收入模式详细识别规则**：

```python
def check_periodic_income(person, all_data, baseline) -> list[PatternMatch]:
    """
    P1: 周期性收入模式
    条件：
    C1: 与特定对手存在≥3个月的收入记录
    C2: 月度收入金额的标准差 < 均值的30%（相对稳定）
    C3: 月度收入时间间隔的标准差 < 10天（相对准时）
    C4: 收入金额偏离个人月均收入基线（非工资类正常收入）
    关键条件：C1必须满足
    """
    matches = []
    for opponent in person_opponents:
        income_months = get_monthly_income(person, opponent)
        if len(income_months) < 3:  # C1
            continue
        amounts = [m['金额'] for m in income_months]
        mean_amt = np.mean(amounts)
        std_amt = np.std(amounts)
        
        # C2: 金额稳定
        c2 = (std_amt / mean_amt < 0.3) if mean_amt > 0 else False
        # C3: 时间稳定
        intervals = compute_intervals(income_months)
        c3 = np.std(intervals) < 10 if len(intervals) >= 2 else False
        # C4: 偏离基线
        c4 = mean_amt > baseline.月均收入 * 0.2  # 超过基线20%
        
        # 匹配度
        conditions_met = sum([c2, c3, c4])
        match_score = 0.6 + 0.15 * conditions_met  # 60%-100%
        
        matches.append(PatternMatch(
            模式='P1-周期性收入',
            匹配度=match_score,
            涉及对手=opponent,
            关键证据=f'与{opponent}有{len(income_months)}个月定期收入，月均{mean_amt:.0f}元',
        ))
    return matches
```

**P3 通讯-资金关联模式详细识别规则**：

```python
def check_comm_fund_link(person, bill_data, call_data) -> list[PatternMatch]:
    """
    P3: 通讯-资金关联模式
    条件：
    C1: 与特定对手通话后24h内出现与该对手的资金往来（≥3次）
    C2: 时序模式为"通话→资金"（而非"资金→通话"）
    C3: 涉及金额>月均交易基线
    关键条件：C1必须满足
    """
    matches = []
    for opponent in common_opponents(person, bill_data, call_data):
        timeline = build_timeline(person, opponent, bill_data, call_data)
        # 检测"通话→24h内→资金"模式
        link_count = count_comm_fund_links(timeline, hours=24)
        if link_count < 3:  # C1
            continue
        
        # C2: 方向判断（通话在先的比例）
        comm_first_ratio = compute_comm_first_ratio(timeline)
        c2 = comm_first_ratio > 0.5
        
        # C3: 金额判断
        avg_amount = compute_avg_link_amount(timeline)
        c3 = avg_amount > baseline.单笔金额均值
        
        conditions_met = sum([c2, c3])
        match_score = 0.6 + 0.2 * conditions_met
        
        matches.append(PatternMatch(
            模式='P3-通讯资金关联',
            匹配度=match_score,
            涉及对手=opponent,
            关键证据=f'与{opponent}有{link_count}次"通话→资金"时序关联',
        ))
    return matches
```

**模式结果数据模型**：

```python
@dataclass
class PatternMatch:
    """行为模式匹配结果"""
    模式编号: str       # P1-P5
    模式名称: str       # 周期性收入模式/...
    匹配度: float       # 0.0-1.0
    涉及对手: str
    关键证据: str
    满足条件: list[str] # ["C1","C2","C3"]
    未满足条件: list[str]
    报告用语: str       # "存在周期性收入特征"
```

**验证方法**：
- 检查点1：P1匹配需要至少3个月数据
- 检查点2：P3匹配需要账单+话单交叉
- 检查点3：匹配度在0.6-1.0范围内
- 检查点4：报告用语不包含法律定性词汇
