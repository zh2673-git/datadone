# 06-01-风险等级评估 - 三阶解构

## 一、是什么（坡度三阶段）

### 阶段1：点出概念

> **一句话定义**：风险等级评估是"红黄绿灯"——将复杂的多维度分析结果浓缩为一个直观的风险判定，帮助决策者快速判断"这个人需不需要优先关注"。

**本质特征**：

| 推导要素 | 逻辑分析 | 结论 |
|---------|---------|------|
| **输入** | 评估基于什么？ | 前5层的全部输出 |
| **输出** | 评估产出什么？ | 一个等级（高/中/低）+ 一个分数（0-100）+ 四维度得分明细 |
| **核心价值** | 评估解决什么问题？ | 降低决策者的认知负荷——不用看50页数据，看一个分数即可判断 |

### 阶段2：建立联系

| 属性名 | 类型 | 说明 | 深入？ |
|-------|-----|-----|-------|
| **异常偏离度维度** | 属性 | 最大偏离σ × 异常数量 → 0-30分 | ❌ 当前文档说明 |
| **行为模式维度** | 属性 | 匹配模式数 × 平均匹配度 → 0-25分 | ❌ 当前文档说明 |
| **证据链维度** | 属性 | 3段链数 × 权重 + 2段链数 × 权重 → 0-25分 | ❌ 当前文档说明 |
| **规模维度** | 属性 | 涉及金额等级 + 人员数等级 → 0-20分 | ❌ 当前文档说明 |

### 阶段3：详细解释

**四维度评分的详细计算**：

| 维度 | 满分 | 计算公式 | 示例 |
|-----|------|---------|------|
| **异常偏离度** | 30 | min(max_sigma/5, 1)×20 + min(异常数/10, 1)×10 | 最大4.2σ+8个异常 = 16.8+8 = 24.8 |
| **行为模式** | 25 | min(模式数/3, 1)×15 + 平均匹配度×10 | 2个模式+70%匹配 = 10+7 = 17 |
| **证据链** | 25 | min(3段链/3, 1)×15 + min(2段链/5, 1)×10 | 2条3段+3条2段 = 10+6 = 16 |
| **规模** | 20 | min(金额/500万, 1)×15 + min(人数/5, 1)×5 | 320万+5人 = 9.6+5 = 14.6 |
| **合计** | 100 | 四维度求和 | 24.8+17+16+14.6 = 72.4 → 高风险 |

**阈值与等级映射**：

| 分数区间 | 等级 | 含义 | 建议动作 |
|---------|------|------|---------|
| 70-100 | 高风险 | 多维度证据指向异常，需优先核查 | 建议立案/重点调查 |
| 40-69 | 中风险 | 部分维度有异常信号，值得关注 | 建议补充数据后判断 |
| 0-39 | 低风险 | 异常信号少或弱 | 暂不优先，存档备查 |

## 二、为什么（坡度三阶段）

### 阶段1：点出概念

> **一句话总结**：风险等级评估的价值在于"降低决策门槛"——将专业分析师才能理解的复杂数据，浓缩为任何人都能理解的红黄绿灯。

### 阶段2：建立联系

| 因果 | 因 | 果 | 逻辑 | 类比 |
|-----|---|---|-----|------|
| **分数可排序** | 多人分析时有统一评分 | 可按风险排序分配调查资源 | 分诊制度 | 急诊先看重症 |
| **分数可追踪** | 同一人在不同时间可重新评估 | 可追踪风险变化趋势 | 复查指标 | 治疗前后对比血压 |
| **明细可解释** | 四维度独立评分 | 知道"风险高在哪里" | 分项诊断 | 不只说"有病"，说"哪里有病" |
| **阈值可配置** | 不同案件敏感度不同 | 可调整高/中/低阈值 | 分级标准 | 不同医院急诊分诊标准可调整 |

## 三、怎么做（坡度三阶段）

### 阶段1：点出概念

> **一句话概述**：按四维度分别打分→加权求和→映射为风险等级。

### 阶段2：建立联系

| 步骤 | 动作 | 产出 | 注意事项 |
|-----|------|------|---------|
| **1.收集输入** | 前5层的分析结果 | 所有中间结果 | 确保无缺失值 |
| **2.四维度打分** | 分别计算异常/模式/证据/规模得分 | 四个0-N分数 | 公式参数可配置 |
| **3.归一化** | 将各维度分数归一化到0-满分范围 | 归一化分数 | 防止溢出 |
| **4.汇总** | 四维度求和 | 总分(0-100) | |
| **5.映射等级** | 按阈值映射高/中/低 | 风险等级 | 阈值可配置 |

### 阶段3：详细解释

**配置化设计**（thresholds.json）：

```json
{
  "risk_assessment": {
    "dimensions": {
      "deviation": {"max_score": 30, "sigma_full": 5, "count_full": 10},
      "pattern": {"max_score": 25, "pattern_full": 3, "match_weight": 10},
      "evidence": {"max_score": 25, "three_seg_full": 3, "two_seg_full": 5},
      "scale": {"max_score": 20, "amount_full": 5000000, "person_full": 5}
    },
    "thresholds": {
      "high": 70,
      "medium": 40
    }
  }
}
```

**验证方法**：
- 检查点1：无异常时总分为0
- 检查点2：极端异常时总分趋近100
- 检查点3：四维度分数之和=总分
- 检查点4：等级与分数阈值一致
