## 一、是什么（坡度三阶段）

### 阶段1：点出概念

> **一句话定义**：风险研判是"报告的结论"——综合前面5层的分析结果，给出线索级的风险判断，从"数据分析"升级为"决策建议"。

**本质特征**：

| 推导要素 | 逻辑分析 | 结论 |
|---------|---------|------|
| **输入** | 研判基于什么？ | 前5层全部输出：基线+异常+量化+模式+因果链 |
| **输出** | 研判产出什么？ | 风险等级+重点人员+行为模式判断+证据充分度+调查建议 |
| **定位** | 研判在报告中的角色？ | **最核心的决策支撑**——报告没有研判=体检报告没有诊断意见 |
| **边界** | 研判能做到什么程度？ | 线索级判断，不是法律定性——"建议进一步核查"而非"确认违纪" |

### 阶段2：建立联系

| 属性名 | 类型 | 说明 | 深入？ |
|-------|-----|-----|-------|
| **风险等级评估** | 子模块 | 综合评分 → 高/中/低 | ✅ 需深入 → [[06-01-风险等级评估-三阶解构]] |
| **重点人员排序** | 子模块 | 按关联度/异常集中度排序对手 | ✅ 需深入 → [[06-02-重点人员排序-三阶解构]] |
| **证据充分度评估** | 属性 | 证据链完整度判断 | ❌ 当前文档说明 |
| **调查方向建议** | 属性 | 基于薄弱环节生成建议 | ❌ 当前文档说明 |

### 阶段3：详细解释

**证据充分度评估**
- **定义**：当前证据链是否足以支撑进一步调查
- **关键点**：
  - **充分**：有时序链+交叉验证+行为模式匹配+多源数据→可直接推动调查
  - **较充分**：有部分证据链+异常识别→建议进一步核查补充
  - **待补充**：仅有零散异常，证据链不完整→建议先补充数据
  - 评估逻辑：基于时序链数量+交叉验证源数+模式匹配数+异常数量

**调查方向建议**
- **定义**：基于当前证据薄弱环节，指出下一步应核查什么
- **关键点**：
  - 生成逻辑：证据链缺什么 → 建议补什么
  - 有通讯资金关联但无职权信息 → "建议核查XX与被核查人的职权关系"
  - 有大额取现但无资金去向 → "建议追踪取现资金的最终去向"
  - 有周期性收入但来源不明 → "建议核查收入来源的合法性"
  - 有特殊关系模式 → "建议核实双方关系的性质"

## 二、为什么（坡度三阶段）

### 阶段1：点出概念

> **一句话总结**：风险研判是"数据分析的终点和决策的起点"——没有研判的报告是数据罗列，有研判的报告才是决策支撑工具。

### 阶段2：建立联系

| 因果 | 因 | 果 | 逻辑 | 类比 |
|-----|---|---|-----|------|
| **无研判则无结论** | 大量分析结果散落 | 决策者无法快速判断 | 无诊断意见的检查报告 | 一堆化验单没有医生解读 |
| **有研判才能决策** | 综合判断呈现 | 领导可以快速决定是否立案 | 诊断意见→治疗方案 | 医生综合判断→决定是否手术 |
| **有建议才有方向** | 指出薄弱环节 | 办案人员知道下一步查什么 | 后续检查建议 | "建议进一步做CT检查" |
| **有评分才能比较** | 不同被核查人的风险可比 | 资源优先分配给高风险 | 分诊制度 | 急诊按严重程度分配资源 |

### 阶段3：详细解释

**风险研判的独特价值定位**：

当前项目的报告止步于"数据呈现"——
- "月支出50万" → 读者需自己判断是否异常
- "与张三交易180万" → 读者需自己判断是否可疑
- "存取现话单匹配2条" → 读者需自己判断是否构成证据

风险研判将以上所有信息综合为——
- "综合风险等级：高（78分）"
- "重点人员：张三（XX局，2条时序链，180万）"
- "证据充分度：较充分，待补充职权关系"
- "建议：优先核查张三与被核查人的职权关系"

**报告价值 = 数据价值 × 研判能力**

## 三、怎么做（坡度三阶段）

### 阶段1：点出概念

> **一句话概述**：将前5层输出按4个维度（异常偏离度/行为模式/证据链/规模）加权评分，汇总为风险等级，并生成重点人员清单和调查建议。

### 阶段2：建立联系

| 步骤 | 动作 | 产出 | 注意事项 |
|-----|------|------|---------|
| **1.异常偏离度评分** | 基于偏离度/异常数量打分 | 0-30分 | 最大偏离σ×异常数量权重 |
| **2.行为模式评分** | 基于匹配到的模式数和匹配度打分 | 0-25分 | 每匹配一个模式加分 |
| **3.证据链评分** | 基于时序链数量和交叉验证数打分 | 0-25分 | 3段链权重>2段链 |
| **4.规模评分** | 基于涉及金额和人员数打分 | 0-20分 | 按金额分级打分 |
| **5.汇总** | 四维度加权求和 → 总分 | 0-100分 | 分数→风险等级映射 |
| **6.重点人员排序** | 按对手关联度/异常集中度排序 | TOP5清单 | 附加对方单位/职务 |
| **7.建议生成** | 基于证据薄弱环节自动生成 | 调查建议列表 | 用模板生成可读文本 |

### 阶段3：详细解释

**风险研判数据模型**：

```python
@dataclass
class RiskAssessment:
    """风险研判结果"""
    本方姓名: str
    
    # 四维度评分
    异常偏离度得分: float   # 0-30
    异常偏离度说明: str     # "月支出偏离基线4.2倍"
    行为模式得分: float     # 0-25
    行为模式说明: str       # "匹配周期性收入+通讯资金关联"
    证据链得分: float       # 0-25
    证据链说明: str         # "2条时序链+3源交叉验证"
    规模得分: float         # 0-20
    规模说明: str           # "涉及金额320万，涉及5人"
    
    # 汇总
    综合风险分数: float     # 0-100
    综合风险等级: str       # 高风险/中风险/低风险
    
    # 重点人员
    重点人员: list[KeyPerson]
    
    # 证据充分度
    证据充分度: str         # 充分/较充分/待补充
    已有证据: list[str]     # ["2条时序链", "3源交叉验证", ...]
    待补充证据: list[str]   # ["职权关系信息", "资金最终去向", ...]
    
    # 调查建议
    调查方向建议: list[str] # ["优先核查...", "建议核查...", ...]
    重点时段: str           # "2024年3月-5月"


@dataclass
class KeyPerson:
    """重点人员"""
    排名: int
    对方姓名: str
    对方单位: str          # 从话单获取
    对方职务: str          # 从话单获取
    关联度评分: float
    通话次数: int
    资金往来金额: float
    时序链数: int
    关联特征: str          # "2条时序链+周期性收入"
```

**评分算法**：

```python
def assess_risk(
    person: str,
    baseline: PersonBaseline,
    anomalies: list[AnomalyItem],
    patterns: list[PatternMatch],
    timeline_chains: list[TimelineChain],
    cross_analysis: dict
) -> RiskAssessment:
    """
    综合风险研判
    """
    # 1. 异常偏离度评分 (0-30)
    max_sigma = max((a.偏离度 for a in anomalies), default=0)
    anomaly_count = len(anomalies)
    dev_score = min(max_sigma / 5, 1) * 20 + min(anomaly_count / 10, 1) * 10
    
    # 2. 行为模式评分 (0-25)
    pattern_count = len(patterns)
    avg_match = np.mean([p.匹配度 for p in patterns]) if patterns else 0
    pattern_score = min(pattern_count / 3, 1) * 15 + avg_match * 10
    
    # 3. 证据链评分 (0-25)
    three_seg_chains = [c for c in timeline_chains if c.链模式 == "通话→资金→通话"]
    two_seg_chains = [c for c in timeline_chains if c.链模式 == "通话→资金"]
    chain_score = min(len(three_seg_chains) / 3, 1) * 15 + min(len(two_seg_chains) / 5, 1) * 10
    
    # 4. 规模评分 (0-20)
    total_amount = sum(a.涉及金额 for a in anomalies)
    person_count = len(set(a.对方姓名 for a in anomalies if a.对方姓名))
    scale_score = min(total_amount / 5000000, 1) * 15 + min(person_count / 5, 1) * 5
    
    # 汇总
    total = dev_score + pattern_score + chain_score + scale_score
    level = "高风险" if total >= 70 else "中风险" if total >= 40 else "低风险"
    
    # 重点人员排序
    key_persons = rank_key_persons(person, anomalies, patterns, timeline_chains, cross_analysis)
    
    # 证据充分度
    evidence_level, existing, missing = assess_evidence(
        patterns, timeline_chains, cross_analysis
    )
    
    # 调查建议
    suggestions = generate_suggestions(missing, key_persons, patterns)
    
    return RiskAssessment(
        本方姓名=person,
        异常偏离度得分=round(dev_score, 1),
        行为模式得分=round(pattern_score, 1),
        证据链得分=round(chain_score, 1),
        规模得分=round(scale_score, 1),
        综合风险分数=round(total, 1),
        综合风险等级=level,
        重点人员=key_persons,
        证据充分度=evidence_level,
        已有证据=existing,
        待补充证据=missing,
        调查方向建议=suggestions,
        # ...
    )
```

**调查建议生成逻辑**：

```python
def generate_suggestions(missing_evidence, key_persons, patterns) -> list[str]:
    """基于证据薄弱环节生成调查建议"""
    suggestions = []
    
    for missing in missing_evidence:
        if "职权关系" in missing:
            for kp in key_persons[:2]:
                if kp.对方单位:
                    suggestions.append(f"优先核查{k kp.对方姓名}（{kp.对方单位}）与被核查人的职权关系")
        if "资金去向" in missing:
            suggestions.append("追踪取现资金的最终去向")
        if "收入来源" in missing:
            suggestions.append("核查周期性收入的来源及合法性")
    
    # 基于行为模式追加建议
    for p in patterns:
        if p.模式编号 == 'P3':
            suggestions.append(f"核查与{p.涉及对手}通讯后资金往来的决策背景")
        if p.模式编号 == 'P2':
            suggestions.append("核查资金快速中转的原因和目的")
    
    return suggestions[:5]  # 最多5条建议
```

**验证方法**：
- 检查点1：综合分数在0-100范围
- 检查点2：风险等级与分数阈值一致
- 检查点3：调查建议不包含法律定性用语
- 检查点4：重点人员排序合理（关联度高的在前）
